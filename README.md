# Bijak dan Selamat — Pendidikan Jasmani Tahun 3

Aplikasi HTML kendiri untuk latihan keselamatan semasa aktiviti fizikal. Dibangunkan dalam Bahasa Melayu untuk guru MUHAMAD SYAWALWAHED, SK (P) JALAN YAHYA AWAL.

## Kandungan
- `index.html`: aplikasi responsif dengan 25 soalan objektif, empat pilihan setiap soalan, maklum balas serta-merta, semakan jawapan, markah /25, peratus, lencana dan cetakan.
- `bank-soalan.md`: semua soalan dan skema jawapan.
- `pemetaan-kurikulum.md`: pemetaan berhati-hati kepada standard yang dapat dikenal pasti dan batasan pengesahan.
- `laporan-pengujian.md`: senarai pemeriksaan kod dan ujian yang belum dilaksanakan secara manual.

## Cara guna
1. Muat turun semua fail ke satu folder.
2. Buka `index.html` menggunakan pelayar moden (Chrome, Edge, Firefox atau Safari).
3. Masukkan nama murid dan pilih **Mula Pembelajaran**.
4. Selesaikan taklimat dan 25 soalan. Pilih satu jawapan; maklum balas akan muncul.
5. Pada keputusan, pilih **Cetak / Simpan PDF**. Pilihan PDF bergantung pada pelayar/peranti.
6. Kemajuan disimpan dalam `localStorage` pelayar yang sama jika tersedia. Ia bukan sistem rekod sekolah dan tidak disegerakkan antara peranti.

## Penerbitan melalui GitHub Pages
1. Log masuk ke GitHub dan cipta repositori baharu, contohnya `pj-tahun3-bijak-selamat`.
2. Muat naik `index.html` ke akar repositori. Fail Markdown boleh dimuat naik sebagai dokumentasi.
3. Buka **Settings → Pages**.
4. Di bawah **Build and deployment**, pilih **Deploy from a branch**, pilih `main` dan folder `/(root)`, kemudian **Save**.
5. Tunggu sehingga GitHub Pages menyatakan penerbitan berjaya. URL lazimnya `https://NAMA-PENGGUNA.github.io/NAMA-REPOSITORI/`; gunakan URL sebenar yang dipaparkan oleh GitHub, bukan contoh ini.
6. Buka URL tersebut dan uji aliran dari telefon serta komputer. Tiada penerbitan dilakukan oleh pembina fail ini, jadi tiada pautan pratonton langsung disediakan.

## Privasi dan keselamatan
- Nama murid diproses pada peranti dan boleh disimpan dalam storan setempat pelayar.
- Elakkan memasukkan nama penuh atau maklumat peribadi sensitif jika peranti dikongsi.
- Aplikasi tidak menghantar data kepada pelayan.
- Kandungan ialah bahan pengukuhan pendidikan; ikut arahan guru dan prosedur keselamatan sekolah.
